# 发明专利初稿

## 一、发明名称

一种软附着惯性测量单元伪影补偿方法

---

## 二、摘要

本发明涉及惯性测量与智能信号处理技术领域，公开了一种软附着惯性测量单元伪影补偿方法。该方法针对惯性测量单元通过皮肤、织物、绑带、柔性套筒或其他非刚性方式附着时所引入的伪影问题，构建软附着惯性信号与刚性参考惯性信号之间的监督式配对映射关系，通过对输入信号进行分段、滑窗、归一化处理，并利用因果型附着状态感知残差时序卷积网络进行补偿，输出更接近刚性参考信号的补偿结果。所述网络包括时间特征提取分支、附着隐状态编码分支、特征门控与平移调制模块以及残差输出模块，并采用由时域重建项、均方误差项、导数一致性项、频谱一致性项和附着隐状态正则项组成的复合损失函数进行训练。本发明能够在不同运动类型、不同附着条件及动态扰动场景下实现对惯性伪影的自适应补偿，并可进一步部署于边缘设备或嵌入式设备进行实时在线补偿。

## 三、权利要求书

### 权利要求1

一种软附着惯性测量单元伪影补偿方法，其特征在于，包括如下步骤：

1. 获取同一运动过程下软附着惯性测量单元信号和刚性参考惯性测量单元信号；
2. 按照预设采样频率对所述软附着惯性测量单元信号和所述刚性参考惯性测量单元信号进行时间对齐，并构建输入输出配对样本；
3. 将所述配对样本划分为多个时序窗口，所述时序窗口作为监督学习输入输出对，其中输入为软附着惯性测量单元窗口 \(X^{nr}\)，输出目标为刚性参考惯性测量单元窗口 \(X^{r}\)；
4. 构建附着状态感知残差时序神经网络，所述网络包括时间特征提取分支和附着隐状态编码分支，所述附着隐状态编码分支用于从时序特征中提取表征传感器附着状态的隐变量；
5. 利用所述附着隐状态对时间特征进行门控调制与平移调制，得到补偿特征，并通过残差输出方式预测软附着惯性测量单元信号对应的补偿量；
6. 将所述补偿量与输入软附着惯性测量单元信号相加，得到补偿输出 \(\hat{X}\)；
7. 采用复合损失函数对所述附着状态感知残差时序神经网络进行训练，所述复合损失函数至少包括时域重建损失、导数一致性损失、频谱一致性损失以及附着隐状态正则项；
8. 在应用阶段，将实时采集到的软附着惯性测量单元信号输入所述已训练网络中，输出补偿后的惯性测量结果。

### 权利要求2

根据权利要求1所述的方法，其特征在于，所述软附着惯性测量单元信号和刚性参考惯性测量单元信号均至少包括三轴加速度信号和三轴角速度信号，输入通道数为6。

### 权利要求3

根据权利要求1所述的方法，其特征在于，所述时序窗口采用滑动窗口方式构建，窗口长度为64个采样点，窗口步长为16个采样点；在一优选实施例中，采样频率为40 Hz。

### 权利要求4

根据权利要求1所述的方法，其特征在于，所述时间特征提取分支采用多层膨胀残差时序卷积结构，卷积核大小为3，膨胀系数按 \(1, 2, 4, 8\) 递增设置，以扩大有效感受野。

### 权利要求5

根据权利要求1所述的方法，其特征在于，所述附着隐状态编码分支用于从时间特征中生成低维附着隐状态序列 \(Z\) 及其窗口级附着状态表示 \(z\)，并通过门控项 \(G\) 和平移项 \(S\) 对主干时序特征进行调制，使调制后的特征满足：

\[
H' = H \odot (1 + G) + S,
\]

其中，\(H\) 为主干时序特征，\(H'\) 为调制后的时序特征，\(\odot\) 表示按元素乘法。

### 权利要求6

根据权利要求1所述的方法，其特征在于，所述补偿输出通过残差方式获得，满足：

\[
\hat{X} = X^{nr} + \Delta X,
\]

其中，\(\Delta X\) 为网络预测的补偿残差。

### 权利要求7

根据权利要求1所述的方法，其特征在于，所述复合损失函数定义为：

\[
\mathcal{L}_{total}
=
\lambda_{1}\mathcal{L}_{L1}
+
\lambda_{2}\mathcal{L}_{MSE}
+
\lambda_{3}\mathcal{L}_{der}
+
\lambda_{4}\mathcal{L}_{spec}
+
\lambda_{5}\mathcal{L}_{att}
+
\lambda_{6}\mathcal{L}_{temp},
\]

其中：

- \(\mathcal{L}_{L1}\) 为时域绝对误差损失；
- \(\mathcal{L}_{MSE}\) 为均方误差损失；
- \(\mathcal{L}_{der}\) 为导数一致性损失；
- \(\mathcal{L}_{spec}\) 为频谱一致性损失；
- \(\mathcal{L}_{att}\) 为附着隐状态幅值正则项；
- \(\mathcal{L}_{temp}\) 为附着隐状态时间平滑正则项。

### 权利要求8

根据权利要求7所述的方法，其特征在于，所述各损失项可进一步定义为：

\[
\mathcal{L}_{L1}
=
\frac{1}{TC}\sum_{t=1}^{T}\sum_{c=1}^{C}
\left|\hat{X}_{t,c}-X^{r}_{t,c}\right|,
\]

\[
\mathcal{L}_{MSE}
=
\frac{1}{TC}\sum_{t=1}^{T}\sum_{c=1}^{C}
\left(\hat{X}_{t,c}-X^{r}_{t,c}\right)^2,
\]

\[
\mathcal{L}_{der}
=
\frac{1}{(T-1)C}
\sum_{t=1}^{T-1}\sum_{c=1}^{C}
\left|
(\hat{X}_{t+1,c}-\hat{X}_{t,c})
-
(X^{r}_{t+1,c}-X^{r}_{t,c})
\right|,
\]

\[
\mathcal{L}_{spec}
=
\frac{1}{KC}
\sum_{k=1}^{K}\sum_{c=1}^{C}
\left|
\left|\mathcal{F}(\hat{X})_{k,c}\right|
-
\left|\mathcal{F}(X^{r})_{k,c}\right|
\right|,
\]

\[
\mathcal{L}_{att}
=
\frac{1}{d}\sum_{i=1}^{d} z_i^2,
\]

\[
\mathcal{L}_{temp}
=
\frac{1}{(T-1)d}\sum_{t=1}^{T-1}\sum_{i=1}^{d}
\left(Z_{t+1,i}-Z_{t,i}\right)^2.
\]

### 权利要求9

根据权利要求1所述的方法，其特征在于，所述附着状态感知残差时序神经网络被配置为因果网络结构，使得当前时刻输出仅依赖当前及历史输入样本，以支持实时在线补偿。

### 权利要求10

一种软附着惯性测量单元伪影补偿系统，其特征在于，包括：

- 数据采集模块，用于获取软附着惯性测量单元信号；
- 预处理模块，用于执行分段、滑窗及归一化处理；
- 推理模块，用于调用根据权利要求1至9任一项所述方法训练得到的补偿模型；
- 输出模块，用于输出补偿后的惯性测量结果。

### 权利要求11

一种计算机可读存储介质，其上存储有计算机程序，所述计算机程序被处理器执行时，实现权利要求1至9任一项所述的方法。

## 四、说明书

### 1. 技术领域

本发明涉及惯性测量、智能信号处理和嵌入式感知技术领域，具体涉及一种软附着惯性测量单元伪影补偿方法，尤其适用于惯性测量单元通过人体皮肤、弹性绑带、柔性套筒、织物或其他非刚性方式附着时产生的运动伪影补偿。

### 2. 背景技术

惯性测量单元（IMU）已广泛应用于人体运动监测、步态分析、康复评估、运动训练、机器人交互和可穿戴感知等场景。在实际应用中，IMU往往并非刚性固定在理想刚体上，而是通过皮肤、衣物、弹性绑带或柔性固定件附着在被测对象表面。此类软附着或非刚性附着方式容易引入附着滑移、局部振动、软组织相对运动及局部耦合变形等现象，导致测得的加速度和角速度信号与真实刚体运动之间存在明显偏差。

现有技术通常采用低通滤波、平滑滤波或简单频域去噪方式抑制该类伪影。然而，软附着惯性伪影并非固定频带的简单噪声，而往往随运动方式、附着松紧程度、局部动力学条件及时间上下文而变化。对于快速、冲击、摇晃或松耦合场景，传统固定滤波方法往往会在抑制伪影的同时削弱真实运动信息，因此难以兼顾时域重建精度、动态一致性和频域一致性。

因此，需要一种能够显式考虑附着状态变化、适应不同运动情形并支持实时在线部署的软附着惯性测量单元伪影补偿方法。

### 3. 发明内容

#### 3.1 要解决的技术问题

本发明旨在解决以下技术问题：

1. 现有软附着IMU测量结果易受附着方式变化影响，导致伪影严重；
2. 传统固定滤波方法难以适应不同运动场景下的非平稳伪影；
3. 现有方法缺少对附着状态的显式建模，难以实现自适应补偿；
4. 现有方法不易部署到实时在线或嵌入式设备中。

#### 3.2 技术方案

为解决上述问题，本发明提供一种软附着惯性测量单元伪影补偿方法。该方法的核心思想是：利用同步采集的软附着IMU信号与刚性参考IMU信号构造监督式配对样本，将软附着惯性伪影补偿问题定义为从软附着惯性信号到刚性参考惯性信号的映射问题，并通过附着状态感知残差时序神经网络学习所述映射关系。

在一优选实施方式中，所述方法包括如下步骤：

1. 采集同一运动试验下的软附着惯性信号和刚性参考惯性信号；
2. 对所述信号进行时间对齐、分段和滑动窗口切分，构造监督式输入输出对；
3. 将每个窗口表示为 \(T \times C\) 的时序矩阵，其中 \(T\) 为窗口长度，\(C\) 为信号通道数；
4. 通过时间特征提取分支提取时序主干特征；
5. 通过附着隐状态编码分支估计表征附着状态的低维隐变量；
6. 利用所述附着隐状态对主干特征进行门控和偏移调制；
7. 通过残差输出模块预测补偿残差，并与输入信号叠加得到补偿结果；
8. 利用复合损失函数训练网络参数；
9. 在部署阶段，将实时采样信号逐点或逐窗口输入网络，实时输出补偿结果。

在一优选实施方式中，网络主干采用因果型残差时序卷积网络，其中隐藏特征维度为64，卷积层数为4，卷积核大小为3，膨胀系数依次为1、2、4、8，附着隐状态维度为8，丢弃率为0.1。上述参数属于优选实施例，本发明并不限于该组数值。

在一优选实施方式中，训练过程采用如下系数配置：

\[
\lambda_{1}=1.0,\quad
\lambda_{2}=0.5,\quad
\lambda_{3}=0.3,\quad
\lambda_{4}=0.2,\quad
\lambda_{5}=0.001,\quad
\lambda_{6}=0.001.
\]

所述配置用于在点值重建、动态一致性、频域一致性以及附着隐状态稳定性之间获得较好的平衡。

#### 3.3 有益效果

与现有技术相比，本发明至少具有如下有益效果：

1. 能够利用刚性参考信号构造监督式补偿目标，从而直接学习伪影补偿映射；
2. 通过引入附着隐状态，实现对传感器附着条件变化的显式建模，提高了对不同运动和不同附着方式的适应能力；
3. 通过残差补偿形式，能够在抑制伪影的同时尽量保留真实运动动态；
4. 通过复合损失函数同时约束时域、动态、频谱及隐状态稳定性，提高补偿结果的整体一致性；
5. 采用因果网络结构，便于在边缘设备、嵌入式设备或实时系统中部署。

### 5. 具体实施方式

以下结合优选实施例对本发明作进一步说明，但本发明的保护范围不限于此。

#### 5.1 数据构建实施例

在一实施例中，采集同一运动试验下的软附着IMU信号与刚性参考IMU信号。每个样本包含三轴加速度和三轴角速度，共6个通道。将连续信号按照固定采样频率进行同步对齐后，采用滑动窗口方式切分为多个长度为64、步长为16的时序片段，并执行逐通道归一化处理，以形成监督学习输入输出对。

#### 5.2 网络结构实施例

在一实施例中，输入信号首先通过输入投影层映射到隐藏特征空间，再依次经过4层膨胀残差时序卷积块提取时间特征。随后，附着状态编码器从时间特征中生成附着隐状态序列及其窗口级摘要，并通过门控项和偏移项调制主干特征。调制后的特征经残差输出层生成补偿残差，最终与输入信号相加得到补偿输出。

#### 5.3 损失函数实施例

在一实施例中，采用复合损失函数对网络进行训练。时域绝对误差项和均方误差项用于约束补偿信号与刚性参考信号的点值接近程度；导数一致性项用于约束信号的一阶动态变化；频谱一致性项用于约束补偿信号与参考信号在频域上的幅值结构接近程度；附着隐状态幅值正则项和时间平滑项用于防止隐状态出现无约束发散或剧烈抖动。

#### 5.4 在线部署实施例

在一实施例中，所述网络配置为因果型结构，使得每一时刻的补偿输出仅依赖当前及历史输入样本。部署时，可在树莓派、Jetson、工业控制器或其他边缘计算平台上运行推理模块，对实时输入的软附着惯性信号进行逐点或逐窗口补偿，并输出补偿后的加速度和角速度结果。

#### 5.5 适用范围说明

本发明不仅适用于人体可穿戴惯性测量场景，也可适用于柔性安装、弹性连接、软耦合连接或非理想固定条件下的其他惯性测量设备信号补偿场景。只要存在软附着或非刚性附着导致的惯性测量偏差，均可采用本发明提出的技术方案进行补偿。
